A tiny Python program that writes one roast of an alarm clock ringing at 6 AM on a Saturday to `/output/entry.txt`. The line casts the alarm as an unpaid intern whose enthusiasm is no substitute for a personality — loud, early, and fired by breakfast.

## Run it

```sh
python3 main.py
```
